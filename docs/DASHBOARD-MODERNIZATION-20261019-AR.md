## ترتيب النقل التالي

1. تركيب Filament جنب `/dashboard` على مسار منفصل، بنفس هوية الجلسة وMFA وسجل التغييرات.
   بدءًا من عرض الطلبة والطلبات والبحث العام ومؤشرات اليوم؛ لا تتحول المالية إلى حفظ Eloquent مباشر.
2. نقل شاشات الإدارة مجالًا بمجال وحذف النظير القديم بعد اكتمال حالات الاستخدام.
   محرر الكورس ورفع الفيديو تجربة مخصصة قائمة؛ لا يُستبدلان بفورم CRUD ناقص.
   في القديم FormRequest وفي المنقول schema للفورم، وقواعد العمل تبقى في الخدمة المالكة.
3. ربط Spatie Permission وShield بعد حسم تعارض حقل `users.role`، وترحيل الدورين الحاليين
   دون توسيع صلاحيات المحرر أو إنشاء طريقة دخول أخرى. المالية ومراجعة البورتفوليو صلاحيات مستقلة.
4. Horizon للطوابير على Redis مع تعريف كل الطوابير الحالية وحدود timeout/retry_after
   وتعديل أمر العامل على Linux عند النشر لاحقًا. وجود الحزمة وحده لا يعني إدارة العامل.
   تقييم Pulse مع Nightwatch وSentry الموجودين، وعدم عرض نظام غير مفعّل باعتباره يعمل.
5. Langfuse Cloud عن طريق OpenRouter Broadcast؛ هذا الربط الرسمي يدعم PHP دون SDK إضافي.
   إعداد الحساب والمفاتيح واستقبال trace فعلي خطوات خارجية لم تُنفّذ ضمن النطاق المحلي.
6. الإجراءات الجماعية والجداول المتجددة والوضع الليلي تأتي من Filament، مع الأذونات
   واستدعاء الخدمات الحالية. التجدد دوري للجداول، وليس وعدًا بحدث فوري عبر WebSocket.
7. إضافة Playwright وaxe-core وLighthouse CI بإصدارات مثبتة. الاختبار المتصفح يكون داخل
   جلسة داش مصرح بها، على الهاتف والديسكتوب، مع فحص الفارغ والأخطاء والتعديل والإجراءات.
   قياس صفحة تسجيل الدخول وحدها لا يعد قياسًا للداش.

## المراجع وحدود إعادة الاستخدام

- [Laravel FormRequest](https://laravel.com/docs/12.x/validation#form-request-validation)
  يُستخدم فعليًا من Laravel المثبت، مع نمط خدمات القراءة الموجود في `AdminStudentReadService`.
- [Laravel eager loading](https://laravel.com/docs/12.x/eloquent-relationships#preventing-lazy-loading)
  للكشف أثناء الاختبارات؛ التحقق من استعلام لكل صف يحتاج أيضًا بيانات متعددة وقياس الاستعلامات.
- [Filament](https://filamentphp.com/) للواجهة ومكوناتها، وليس لإعادة ابتكار قواعد ركن.
  فحص Composer التجريبي نجح مع Filament 5.10.2 وShield 4.3.1 وSpatie Permission 8.3.0
  دون تحديث Laravel أو الحزم الحالية. الفحص التجريبي لا يعني تركيبها أو اعتماد واجهتها.
- [Spatie prerequisite](https://spatie.be/docs/laravel-permission/v8/prerequisites)
  يوضح تعارض اسم role، لذلك لا يُركب HasRoles عشوائيًا على User الحالي.
- [Langfuse مع OpenRouter](https://langfuse.com/integrations/gateways/openrouter)
  و[Broadcast](https://openrouter.ai/docs/guides/features/broadcast/overview) هما مسار الربط المختار.
- [Horizon](https://laravel.com/docs/12.x/horizon) و[Pulse](https://laravel.com/docs/12.x/pulse)
  مصادر التنفيذ الرسمي عند الوصول إلى مرحلة التشغيل.

لم تُنسخ شيفرة من تطبيق مغلق المصدر.
