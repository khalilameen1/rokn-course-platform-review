## لازم كودكس يعمله قبل الرفع
1. تشغيل CI كامل على الفرع (الباك والموبايل والداش).
2. الموبايل: `npm run verify:release` كامل، وبعدين build حقيقي (اتضافت مكتبة JS بس، `@react-navigation/bottom-tabs`، من غير native modules جديدة).
3. الداش: `npm ci` في `backend/` بيسطّب `tus-js-client@4.3.1`، و`npm run production` بينسخه لـ`public/admin/assets/js/vendor/tus-js-client/`.
4. الـmigrations الجديدة بتاريخ 2026_10_17. لو كوبونين في staging بقوا بنفس الكود بعد التوحيد، الـmigration هيقف ويقول أرقامهم، غيّر اسم واحد فيهم.
5. بعد أي migration جديد: `php scripts/lock-migrations.php --write`.
6. البوابات الأربع في `docs/LAUNCH-DAY-RUNBOOK-AR.md` (دفعة كاشير تجريبية، إعدادات Cloud، تجربة على جهاز، اختبار تحمّل بـ`backend/scripts/load/launch-smoke.js` على staging).
7. شغل صفحة الهبوط بتاعك: شغّل `vendor/bin/pint` على ملفاته السبعة قبل الـcommit، لأن CI بقى بيرفض أي ملف مش متنسق.
8. قبل ما تعمل commit لشغل صفحة الهبوط: الملفات المشتركة الثلاثة (فوق) فيها تعديلاتك + تعديلات الفرع مع بعض في الشجرة، وكلها متحقّق منها (`verify:public-assets` نضيف). اعمل commit ليها زي ما هي.
